# Liquid Glass

Manifest-only theme contribution with a required no-op backend factory. No application entry, commands, services, storage, or injected agent skills.

- `themes/pearl.css`: palette, progressive glass effects, host selectors, and fallback rules.
- `theme.test.mjs`: package and CSS contract checks.
- `COMPATIBILITY.md`: observed host hooks and validation evidence.
- `README.md`: local installation and rollback.
